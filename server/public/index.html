Audacity Spectrogram Configuration

1. Import intercepted_wiretap.wav.
2. Click the track dropdown chevron ▼ on the left panel → select Spectrogram.
3. Click the dropdown ▼ again → Spectrogram Settings....
4. Change Scale from Logarithmic to Linear.
5. Set Max Frequency to 16000 Hz and Min Frequency to 7000 Hz.
6. Zoom in between 2.5s and 14.5s to read the text.

Manual Error Level Analysis (ELA) with GIMP

Follow this 5-step forensic procedure in GIMP to detect compression differentials:

  1. Open Target: File → Open (e.g., crime_scene_evidence.jpg or evidence_clearance_badge.jpg).
  2. Export Reference: File → Export As... → temp_resave.jpg. Set JPEG Quality to 90% and export.
  3. Load as Layer: File → Open as Layers... → temp_resave.jpg.
  4. Set Difference Mode: In the Layers panel, switch the top layer Mode from Normal to Difference.
  5. Amplify & Inspect: Go to Layer → New from Visible, then open Colors → Levels (or Brightness-Contrast). Drag the white input slider left to amplify the subtle compression error.

Forensic Interpretation:

1. Natural High-Frequency Edges: Sharp color transitions (such as yellow evidence markers A & B) naturally show high-frequency edge response. Notice their interior surfaces are dark.
2. Areal Compression Tampering: A digitally staged object or spliced credential block will show high error across its entire body (cylinder, barrel, grip, tag or badge patch), proving it originated from a different compression generation.

Audacity Stereo Channel Decoupling

1. Open covert_broadcast.wav in Audacity.
2. Click the track title dropdown chevron ▼ → select Split Stereo Track.
3. Notice that Track 1 (Left Channel) and Track 2 (Right Channel) can now be inspected individually.
4. Set both tracks to Spectrogram View (Linear scale, 5,000 Hz – 14,000 Hz).
5. Read the first half of the flag in the Left track, and the second half in the Right track!
